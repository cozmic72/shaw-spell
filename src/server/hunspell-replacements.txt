# Hunspell REP table for Shavian spell-checking.
#
# Two classes of rules below:
#
# 1. Bidirectional vowel/consonant swaps — common typos a user might make
#    by picking the "wrong" letter of a phonetically-similar pair. Listed
#    in both directions so either wrong→right or right→wrong can fire.
#
# 2. Always-wrong compound-letter decompositions. Shavian's six compound
#    letters (𐑸 𐑹 𐑺 𐑻 𐑼 𐑽 𐑿) are never correctly spelled as their
#    component sequence; these REPs nudge suggestions back to the
#    compound form. Directional (wrong→right only).
#
# See also: PH_RULES in generate_spellcheck.py for the suggestion-ranking
# rules (happy-tensing, cot-caught, trap-bath, etc.) that go into the
# .dic via ph: annotations rather than the .aff.
